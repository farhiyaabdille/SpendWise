# Publish SpendWise to the Internet

## Part 1: Deployment Readiness

Review your SpendWise project and ensure its files are organized
correctly. A simple HTML, CSS, and JavaScript project may look like
this:

``` text
SpendWise/
├── index.html
├── style.css
├── script.js
└── assets/
    └── images/
```

Check that all files are present, paths are correct, assets are in the
right folders, and the website works locally.

## Part 2: GitHub Repository

1.  Sign in to GitHub.
2.  Create a repository named `SpendWise`.
3.  Set its visibility to **Public**.
4.  Upload your project files and folders.
5.  Commit the files.

## Part 3: Netlify Deployment

1.  Sign in to Netlify.
2.  Choose **Add new project** or **Import an existing project**.
3.  Import from GitHub and authorize access if requested.
4.  Select the `SpendWise` repository.
5.  Configure the deployment settings.

For a simple HTML, CSS, and JavaScript project: - Branch: `main` - Build
command: leave blank - Publish directory: `.`

If your project uses a framework such as Vite or React, use the
appropriate build command and publish directory.

6.  Deploy the site and wait for Netlify to finish.
7.  Copy the live website URL.

## Part 4: Custom Site Name

1.  Open the deployed site in Netlify.
2.  Open site configuration or site settings.
3.  Find the option to change the site name.
4.  Choose an available name related to SpendWise, such as
    `spendwise-farhiya`.
5.  Save the change.

The live URL will look like `https://your-site-name.netlify.app`.

## Part 5: Continuous Deployment Test

1.  Make a visible change to the SpendWise application.
2.  Save the changed file.
3.  Commit and push the change to GitHub.
4.  Check the Deploys section in Netlify.
5.  Wait for deployment to finish.
6.  Refresh the live website and confirm the change appears.

This confirms that Netlify automatically deploys updates pushed to
GitHub.

## Part 6: Final Testing

Confirm that: - All pages load correctly. - Styles and layouts display
correctly. - JavaScript functions work. - Images and other assets
load. - Navigation links work. - The website displays correctly on
mobile and desktop. - The latest GitHub changes appear on the live
website.
